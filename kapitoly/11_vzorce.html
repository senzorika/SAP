1. Základné štatistické vzorce

1.1 Priemer (aritmetický priemer)

Vzorec priemeru
x̄ = (1/n) × Σ(xᵢ) Kde: • x̄ = aritmetický priemer • n = počet pozorovaní • xᵢ = hodnota i-tého pozorovania • Σ = suma

Praktické využitie: Priemerné hodnotenie intenzity chuti panelistami na 9-bodovej hedonickej škále.

1.2 Štandardná odchýlka

Vzorec štandardnej odchýlky
s = √[(1/(n-1)) × Σ(xᵢ - x̄)²] Kde: • s = štandardná odchýlka • n-1 = stupne voľnosti • xᵢ - x̄ = odchýlka od priemeru

Poznámka: Používa sa n-1 (Besselova korekcia), pretože pracujeme s vzorkou, nie s celou populáciou.

1.3 Konfidenčný interval

Vzorec konfidenčného intervalu
CI = x̄ ± t(α/2, n-1) × (s/√n) Kde: • t(α/2, n-1) = kritická hodnota t-rozdelenia • α = hladina významnosti (typicky 0.05) • s/√n = štandardná chyba priemeru

Interpretácia: Postup konštrukcie intervalu zachytí skutočný priemer populácie v 95 % opakovaní experimentu (pre jeden konkrétny interval to nie je „95 % pravdepodobnosť“).

Vzorec CV
CV = (s / x̄) × 100%

2. Rozlišovacie testy

2.1 Binomická pravdepodobnosť

Binomická pravdepodobnosť
P(X = k) = C(n,k) × p^k × (1-p)^(n-k) Kde: • n = počet pokusov (panelistov) • k = počet úspešných identifikácií • p = pravdepodobnosť úspechu pri náhodnom výbere • C(n,k) = binomický koeficient Pre trojuholníkový test: p = 1/3 (tri vzorky, z toho jedna odlišná — pravdepodobnosť uhádnutia)

2.3 Výpočet počtu panelistov

Vzorec pre počet panelistov
n = [Z(α)·√(p₀(1−p₀)) + Zβ·√(p(1−p))]² / (p − p₀)² Kde: • Z(α) = kritická hodnota pre hladinu významnosti (jednostranne 1.645 pre α = 0.05) • Zβ = kritická hodnota pre silu testu (power) • p = očakávaná úspešnosť panelistov • p₀ = náhodná úspešnosť (1/3 pre trojuholníkový test)

Vzorec platí pre jednostranný rozlišovací test (normálna aproximácia). Rozlišovacie testy sú jednostranné (H₁: p > p₀), preto sa používa Z(α), nie Z(α/2). Presnejší je priamy binomický výpočet (napr. sensR::discrimSS()).

3. ANOVA a post-hoc testy

3.1 F-statistika

F-statistika
F = MS(between) / MS(within) F = [SS(between) / df(between)] / [SS(within) / df(within)] Kde: • MS(between) = stredný štvorcový rozptyl medzi skupinami • MS(within) = stredný štvorcový rozptyl v rámci skupín • SS = suma štvorcov • df = stupne voľnosti df(between) = k - 1 (k = počet skupín) df(within) = N - k (N = celkový počet pozorovaní)

3.2 Tukey HSD (Honestly Significant Difference)

Tukey HSD
HSD = q(α, k, N-k) × √(MS(within) / n) Kde: • q(α, k, N-k) = študentizovaný rozsah • k = počet skupín • N-k = stupne voľnosti reziduá • n = počet pozorovaní na skupinu

Používa sa pri porovnaní viacerých experimentálnych skupín s jednou kontrolnou skupinou.

Dunnettov test
tD = (x̄ᵢ - x̄(control)) / √[MS(within) × (1/nᵢ + 1/nc)]

3.4 Bonferroni korekcia

Bonferroni korekcia
α(adjusted) = α / m Kde: • α = pôvodná hladina významnosti • m = počet porovnaní Príklad: Pri α = 0.05 a 6 porovnaniach: α(adj) = 0.05/6 = 0.0083

4.2 Lineárna regresia

Lineárna regresia
y = β₀ + β₁x + ε Odhad parametrov: β̂₁ = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / Σ(xᵢ - x̄)² β̂₀ = ȳ - β̂₁x̄ Kde: • β₀ = intercept (posunutie) • β₁ = sklon (slope) • ε = chyba (reziduum)

R²

5. Shelf-life vzorce

5.1 Q10 model

Q10 model
Q10 = k(T+10) / k(T) Kde: • k(T+10) = rýchlosť degradácie o 10°C vyššej teploty • k(T) = rýchlosť degradácie pri teplote T
ProcesQ10 hodnota
Enzymatická degradácia2-3
Oxidácia lipidov2-4
Reakcie Maillardovej3-5
Mikrobiálny rast2-5
Strata vitamínov2-10

Orientačné hodnoty — silno závisia od matrice, aw a teplotného rozsahu.

5.2 Arrheniusov model

Arrheniusov model
k = A × e^(-Ea/RT) Kde: • k = konštanta rýchlosti reakcie (s⁻¹) • A = preexponenciálny faktor (s⁻¹) • Ea = aktivačná energia (J/mol) • R = univerzálny plynový konštanta (8.314 J/(mol·K)) • T = absolútna teplota (K) Lineárna forma: ln(k) = ln(A) - (Ea/R) × (1/T)

5.3 Weibull distribúcia

Weibull distribúcia
F(t) = 1 - e^(-(t/η)^β) Kde: • F(t) = kumulatívna distribúcia poruchy • t = čas • η = charakteristický čas (scale parameter) • β = tvarový parameter (shape parameter)
βVýznam
β < 1Klesajúca intenzita poruchy (early failures)
β = 1Exponenciálne rozdelenie (konštantná intenzita)
β > 1Rastúca intenzita poruchy (wear-out failures)

Predošlá verzia mala interpretáciu β < 1 a β > 1 obrátenú.

6.2 Just Noticeable Difference (JND)

JND je najmenšia zmena intenzity stimulu, ktorú subjekt dokáže zaznamenať. Vzťah k Weberovmu zákonu:

JND a Weberov zákon
JND = k × I Kde: • k = Weberov zlomok • I = intenzita stimulu

6.3 Weberov zákon

Weberov zákon
ΔI / I = k Kde: • ΔI = JND (minimálna zmena) • I = počiatočná intenzita • k = Weberov zlomok (konštanta)
StimulWeberov zlomok (k)
Hmotnosť (záťaž)~0.02
Hlasitosť (intenzita zvuku)~0.1
Chuťové podnety (sacharóza, NaCl, kyseliny)~0.1–0.3
Horkosť (chinín, kofeín)~0.2–0.3

Orientačné hodnoty; chuťové Weberove zlomky sa v literatúre značne líšia podľa metódy a koncentrácie (Lawless & Heymann, 2010). Kapsaicín nie je horká látka — vyvoláva pálivosť (chemestéza, receptor TRPV1).

6.4 Stevensov zákon

Stevensov zákon
ψ = k × I^n Kde: • ψ = subjektívna intenzita • k = konštanta • I = fyzikálna intenzita • n = exponent (špecifický pre každý stimul)
StimulnVzťah
Hlasitosť (akustický tlak, tón 3 kHz)0.67Podlineárny (kompresívny)
Sladkosť (sacharóza)1.3Nadlineárny
Sladkosť (sacharín)0.8Podlineárny
Slanosť (NaCl)1.3Nadlineárny
Dĺžka čiary1.0Lineárny
Hmotnosť (tiaž)1.45Nadlineárny

Hodnoty podľa S. S. Stevensa (1957, 1975); exponent je < 1 kompresívny, > 1 expanzívny. Konkrétne hodnoty závisia od metódy a rozsahu podnetov.

Krok 1: Výpočet priemeru

x̄ = (6.2 + 5.8 + 6.5 + 6.0 + 5.5 + 6.3 + 5.9 + 6.1 + 6.4 + 5.7 + 6.0 + 6.2) / 12 = 72.6 / 12 = 6.05

Krok 2: Výpočet štandardnej odchýlky

s = √[ Σ(xᵢ − 6.05)² / 11 ] = √(0.950 / 11) = √0.0864 = 0.294

Krok 3: Výpočet štandardnej chyby

SE = s / √n = 0.294 / √12 = 0.294 / 3.464 = 0.085

Krok 4: Nájdenie t-hodnoty

Pre α = 0.05 (dvojstranný) a df = 11: t(0.025, 11) = 2.201

Krok 5: Výpočet konfidenčného intervalu

CI = 6.05 ± 2.201 × 0.085 = 6.05 ± 0.187
Výsledok: 95% CI = [5.86, 6.24]

x̄ = 6.05 | SS = 0.950 | s = 0.294 | SE = 0.085 | t(0.025, 11) = 2.201

CI = 6.05 ± 2.201 × 0.085 = 6.05 ± 0.187

Interpretácia: Na 95 % hladine spoľahlivosti leží priemerná intenzita sladkosti produktu (v populácii hodnotení tohto panelu) medzi 5.86 a 6.24 na škále 0–10. (Predošlá verzia mala chybný súčet štvorcov 0.825.)
