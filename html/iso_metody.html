2. Trojuholníkový test (Triangle Test)

Princíp trojuholníkového testu

Princíp: Panelista dostane tri vzorky, z ktorých sú dve rovnaké a jedna odlišná. Úlohou je identifikovat odlišnú vzorku.

Výpočet

H0: p = 1/3 (náhodná voľba) H1: p > 1/3 (schopnosť rozlišovať) P(X ≥ k) = Σ (n choose i) × p^i × (1-p)^(n-i)

3. Duo-trio Test

Princíp duo-trio testu

Princíp: Panelista dostane referenčnú vzorku a dve neznáme vzorky (jedna rovná referencii, jedna odlišná).

  • Menej náročný na panelistov

Nevýhody

  • Pri danom d′ približne rovnako nízka sila ako trojuholník
  • Vyžaduje konzistentnú referenciu

4. Párový porovnávací test

Princíp párového porovnávacieho testu

Princíp: Panelista dostane dve vzorky a vyberie tú, ktorá je viac intenzívna v konkrétnom atribute.

6. Výpočty a štatistika

6.1 Binomické rozdelenie

P(X = k) = C(n,k) × p^k × (1-p)^(n-k) Kde: - n = počet panelistov (pokusov) - k = počet správnych odpovedí - p = pravdepodobnosť správnej odpovedi pri náhodnej voľbe - C(n,k) = n! / (k! × (n-k)!)

6.3 Výpočet počtu panelistov

n ≈ [ z_α·√(p₀(1−p₀)) + z_β·√(p₁(1−p₁)) ]² / (p₁ − p₀)² Kde: - p₀ = pravdepodobnosť uhádnutia (1/3 alebo 1/2) - p₁ = p₀ + p_d·(1 − p₀), p_d = podiel „rozlišujúcich" hodnotiteľov - z_α = 1.645 (α = 0.05, jednostranne), z_β = 0.842 (sila 0.80) Príklad: trojuholník, p_d = 25 % → p₁ = 0.50 n ≈ 52 (aproximácia); presný binomický výpočet: n = 60
Rovnaký senzorický rozdiel (d′ = 1), α = 0.05, sila 0.80: 2-AFC 26 · 3-AFC 22 · tetrad 65 · trojuholník 220 · duo-trio 241 hodnotiteľov. Vzorec n = z²·p(1−p)/E² (šírka CI) na plánovanie rozlišovacieho testu nie je vhodný. Precvič v R: SaIT cvičenie 14.
